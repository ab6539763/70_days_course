## 3. Python 程序执行流程（第一个程序）

```mermaid
flowchart TD
    A[编写 .py 源文件] --> B[保存 UTF-8 编码]
    B --> C{运行方式}
    C -->|VS Code 运行| D[调用 Python 解释器]
    C -->|终端 python main.py| D
    D --> E[自上而下执行语句]
    E --> F{遇到 input?}
    F -->|是| G[阻塞等待用户键盘]
    G --> E
    F -->|否| H{遇到 print?}
    H -->|是| I[输出到标准输出 stdout]
    I --> E
    H -->|否| J[继续下一行]
    J --> K{文件结束?}
    K -->|否| E
    K -->|是| L[进程退出]
```

## 4. 个人信息卡片业务流程

```mermaid
flowchart TD
    Start([开始]) --> Welcome[打印欢迎语]
    Welcome --> Name[输入姓名]
    Name --> VName{非空?}
    VName -->|否| Name
    VName -->|是| Age[输入年龄]
    Age --> VAge{正整数?}
    VAge -->|否| Age
    VAge -->|是| City[输入城市]
    City --> Job[输入职业]
    Job --> Motto[输入座右铭]
    Motto --> Build[组装 profile 字典]
    Build --> Render[渲染边框名片]
    Render --> AskSave{是否保存文件?}
    AskSave -->|是| Write[写入 output/card.txt]
    AskSave -->|否| End
    Write --> End([结束])
```
