---

## 1. 项目背景

培训课程第一天，学员刚接触 Python。需要一个 **零第三方依赖**、**纯标准库**、**5-15 分钟可完成核心功能** 的小项目，建立「输入 → 处理 → 输出」的程序观，并为后续 JSON、API 字段处理埋伏笔。

---

## 2. 项目目标

### 2.1 业务目标（教学视角）

- 学员体验完整的「需求 → 编码 → 运行 → 修改」闭环
- 巩固 `input`、`print`、变量、基本数据类型
- 引入 f-string 格式化输出（Day 2 深化）

### 2.2 用户故事

> 作为一名课程学员，我希望在终端里输入我的姓名、年龄、城市、职业和一句自我介绍，程序能打印一张格式整齐的个人名片，让我有成就感并愿意继续学下去。

---

## 3. 功能需求

### 3.1 功能列表

| ID | 功能 | 描述 | 验收标准 |
|----|------|------|----------|
| F01 | 采集姓名 | 提示用户输入姓名 | 非空校验，空则提示重新输入 |
| F02 | 采集年龄 | 提示输入年龄 | 必须为正整数，非法则提示 |
| F03 | 采集城市 | 提示输入所在城市 | 允许中文/英文 |
| F04 | 采集职业 | 提示输入职业或学习目标 | 字符串存储 |
| F05 | 采集座右铭 | 一句自我介绍或学习目标 | 最长 200 字符 |
| F06 | 生成名片 | 边框 + 对齐输出 | 见 UI 规范 |
| F07 | 可选保存 | 将信息写入 `output/card.txt` | 文件 UTF-8 编码 |

### 3.2 非功能需求

| 类型 | 要求 |
|------|------|
| 兼容性 | Python 3.10+，Windows / macOS / Linux |
| 依赖 | 仅标准库，不使用 pip 第三方包 |
| 编码 | 源文件 UTF-8，支持中文 |
| 可维护性 | 函数拆分，`main()` 入口清晰 |

## 4. UI / 输出规范（终端）

```
╔══════════════════════════════════════╗
║         个 人 信 息 卡 片            ║
╠══════════════════════════════════════╣
║  姓名：张三                          ║
║  年龄：28 岁                         ║
║  城市：上海                          ║
║  职业：产品经理 · 转型大模型开发      ║
╠══════════════════════════════════════╣
║  座右铭：                            ║
║  70天后，我要独立做出自己的 RAG 应用  ║
╚══════════════════════════════════════╝
```

- 边框字符可使用 `═` `║` `╔` `╗` 等 Unicode 框线
- 宽度建议固定 38-42 字符，过长座右铭自动换行（进阶）
