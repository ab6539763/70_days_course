# Day 1 旁白导读：为什么「第一行代码」值得你用一整天

---

## 【课前 3 分钟 · 讲师旁白】

各位同学，欢迎走进这门 **70 天零基础大模型应用开发** 课程。

我知道很多人心里会有一个声音：「我能不能直接跳到调 API、做 RAG、做 Agent？」——可以理解，那些东西听起来更酷。但我必须很负责任地告诉你：**跳过的每一级台阶，都会在第 25 天、第 40 天以 Bug 和挫败感的形式找回来。**

我们今天不做花里胡哨的东西。今天只做三件看似朴素、实则决定你后面 69 天能不能站稳的事：

1. **把开发环境装对** —— 工欲善其事，必先利其器。环境装错一次，你可能浪费整整一个下午在搜索引擎里打转。
2. **理解变量与数据类型** —— 大模型 API 返回的全是 JSON，JSON 的本质就是「字典套字典、列表套字符串」。今天学的 `dict` 和 `str`，就是 70 天后你读接口文档的母语。
3. **写出第一个能跑的程序，并把它提交到 Git** —— 从第一天起，你就按「工程师」而不是「游客」的方式学习。

## 【与明日衔接 · Day 2 预告】

明天我们进入 **运算符与字符串**。你会学到 `split`、`strip`、`replace`——这些不是背概念，而是后面写 **Prompt 模板**、清洗用户输入、处理模型返回文本的基本功。今天写的「个人信息卡片」里姓名字段，明天会被你升级成「自动去空格、统一大小写」的健壮版本。

**今日务必打牢**：`str` 类型、`input()`、`print()`、f-string 初印象（明天系统讲）。

---

## 【学习心态建议】

- **允许自己慢**：第一天记不住语法很正常，重要的是「跑通」和「敢改」。
- **不要复制粘贴不看**：每一行敲进去，改一个字母看报什么错——错误信息是最好的老师。
- **遇到报错先读最后一行**：90% 的初学者问题都在 Traceback 最后一行写着 `SyntaxError` 或 `NameError`。
- **今晚作业必做**：作业不是刁难你，是把上午听懂的变成下午能写的。

## 【常见误区 · 讲师敲黑板】

| 误区 | 正解 |
|------|------|
| 「先学数学再学编程」 | 应用开发优先动手能力，数学在 Day 15 用大白话讲 Transformer |
| 「Mac 和 Windows 命令完全一样」 | 路径分隔符、终端默认 shell 不同，课件给双平台对照 |
| 「print 调试丢人」 | 企业里照样用，后期才用断点调试 |
| 「Git 以后再说」 | 从 Day 1 养成版本习惯，毕业时你会有一个能展示的 GitHub |
