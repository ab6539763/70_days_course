# 零基础大模型应用开发 · 70 天培训课程课件

> 完整 Markdown 课件 · 支持导出 PDF / PPTX · 环环相扣 · 从零到就业

## 课程概览

| 项目 | 说明 |
|------|------|
| **培训周期** | 70 天（10 周），每天约 6-8 小时 |
| **目标学员** | 零编程基础或仅有少量基础的转行者、在校生、产品经理 |
| **培养目标** | 能独立开发 RAG 应用、Agent 应用、微调小模型并部署上线 |
| **课件总量** | 70 天 × 完整讲义，共约 40,000+ 行 Markdown |

## 课件设计原则

1. **前 2 周 Python 打底**：每天实操项目巩固，练习均朝向「调 API、处理 JSON、封装服务」等大模型开发真实技能
2. **理论点到为止**：Transformer 等原理只做通俗科普，时间留给应用开发
3. **三大核心能力递进**：Prompt 工程 → RAG → Agent，微调作为加分项
4. **项目驱动**：4 个完整项目贯穿始终，确保简历上有拿得出手的作品
5. **环环相扣**：每天的「上节回顾」与「明日预习」形成完整知识链，无断点
