# 零基础大模型应用开发 70 天培训课程 · 全套课件

> 本仓库是一套面向零基础学员的大模型应用开发实训课件,共 70 天。
> 每一天一个独立目录,内含:当日完整课件(含旁白解读、流程图、需求文档、架构设计、示意图、课堂笔记)、全部实操代码(带详细注释)、课后作业与参考答案。
> 课件之间严格按天衔接:每天开头回顾昨天、结尾预告明天,所有项目代码逐天演进,不做孤立示例。

## 四、每日课件的统一结构

每个 `dayXX/` 目录固定包含:

```
dayXX/
├── DayXX-课件.md        # 当日完整课件正文(旁白解读 + 上午授课 + 下午实操 +
│                        #   流程图 + 需求文档 + 架构设计 + 课堂笔记 + 排错手册)
├── 作业与答案.md         # 当日课后作业(选择 + 填空 + 编程 + 思考题)与逐题详解
├── code/                # 当日全部实操代码,带企业级详细注释
└── homework/            # 作业编程题的参考答案代码
```

课件正文内部的固定章节:

1. **旁白解读**:承上启下——昨天学了什么、今天为什么学这个、明天要用它做什么;
2. **上午授课**:概念讲解,全部用业务场景与生活类比切入,配示意图;
3. **下午实操**:一个完整的小项目,包含需求文档 → 流程图 → 架构设计 → 迭代式编码;
4. **课堂笔记**:当天知识点速查表,方便复习;
5. **常见错误与排错手册**:真实初学者高频踩坑合集;
6. **明日预告**:说明今天的产出如何被明天复用。

## 五、代码运行约定

- Python 版本:3.10 及以上;
- 所有依赖统一记录在各天 `code/requirements.txt`;
- 从 Day 12 起需要大模型 API Key(推荐 DeepSeek,注册即送免费额度),统一放在 `.env` 文件,**严禁提交到 Git**;
- 从 Day 51 起需要租用云 GPU(AutoDL / 魔搭,约 2 - 5 元/小时)。

## 六、学习方法建议

1. **不要只看,要敲**:所有代码必须亲手敲一遍,复制粘贴等于没学;
2. **每天提交 Git**:从 Day 1 起养成习惯,70 天后你的 GitHub 主页就是简历;
3. **作业必须做**:作业里藏着第二天课程的伏笔,跳过作业会跟不上;
4. **错误是常态**:遇到报错先看"排错手册"一节,再自己 Google/问 AI,最后问讲师——这个顺序就是工程师的日常。
