### 2.2 Ragas 评估框架实战、构建测试集

#### RAG 完整链路

```
文档 → 加载 → 分割 → 向量化 → 存储 → 检索 → 增强生成 → 回答
```

#### 核心公式（通俗版）

> 用户问题 → 转成向量 → 在知识库中找最相似的文本块 → 塞进 Prompt → 大模型生成回答

#### 关键参数

| 参数 | 作用 | 调优建议 |
|------|------|----------|
| chunk_size | 每个文本块大小 | 300-1000 字符 |
| chunk_overlap | 块之间重叠 | chunk_size 的 10-20% |
| top_k | 检索返回数量 | 3-10 |
| similarity_threshold | 相似度阈值 | 0.5-0.8 |
