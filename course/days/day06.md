## 深度讲义


### 6.1 函数定义

```python
def greet(name: str, greeting: str = "你好") -> str:
    """问候函数"""
    return f"{greeting}, {name}!"

# 位置参数
greet("张三")

# 关键字参数
greet(name="李四", greeting="Hello")

# *args: 接收任意数量的位置参数
def sum_all(*args):
    return sum(args)
sum_all(1, 2, 3, 4)  # 10

# **kwargs: 接收任意数量的关键字参数
def print_info(**kwargs):
    for k, v in kwargs.items():
        print(f"{k}: {v}")
```

### 6.2 lambda 匿名函数

```python
square = lambda x: x ** 2
print(square(5))  # 25

# 常用于排序
users = [{"name": "张三", "age": 25}, {"name": "李四", "age": 20}]
users.sort(key=lambda u: u["age"])
```
