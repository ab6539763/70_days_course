## 二、理论精讲（纳米级拆解）


### 2.1 微调前后效果对比评估、过拟合识别与处理

#### 微调 vs RAG vs Prompt 决策树

```
数据是公开知识？ → RAG
需要改变模型行为/风格？ → 微调
只是临时任务？ → Prompt 工程
```

#### LoRA 原理（通俗版）

> 不改动大模型全部参数，只训练一小撮「适配器」参数。
> 就像给一本厚书贴便利贴，而不是重写整本书。

#### 显存估算（经验公式）

> 7B 模型 LoRA 微调约需 16-24GB 显存
> 用 QLoRA 可降到 8-12GB
