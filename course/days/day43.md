## 二、理论精讲（纳米级拆解）


### 2.1 多 Agent 架构模式: Supervisor 模式、协作模式、层级模式

#### Agent vs Chain

| | Chain | Agent |
|---|-------|-------|
| 执行方式 | 固定步骤 | 自主决策 |
| 灵活性 | 低 | 高 |
| 适用场景 | 翻译、摘要 | 复杂任务、多步推理 |

#### ReAct 循环

```
Thought（思考）→ Action（行动）→ Observation（观察）→ Thought → ...
```

#### 核心组件

1. **LLM**: 大脑，负责推理
2. **Tools**: 手脚，负责执行（搜索、计算、查数据库）
3. **Memory**: 记忆，维护上下文
4. **Planner**: 规划器（LangGraph 中实现）
