**7. B。** cls 即类自己;cls(...) 造对象,继承时自动指向子类(明天见效)。
**8. B。** from_xxx 工厂模式的标准归宿。LangChain 的 from_messages/from_env 全是它。
**9. B。** 忘了括号拿到的是类本身(注册表模式的既视感)。`ContactBook.count()` 缺 self 报 TypeError。
**10. B。** 错误离出生点越近越便宜:role 拼错当场现形五秒修好,不校验则三天后 API 400 排查两小时。

### 读程序题答案与解析

**1.** `2 1`。两个对象的 n 各自独立(实例属性)。
**2.** `2.0 1.0 1.0`。通过实例赋值不会改类属性,而是给 c1 挂了个同名**实例属性**遮住类属性;c2 和类本身不受影响。这就是排错手册错误 5 的"分裂"现象。
**3.** `Msg ''`。类方法工厂 empty 用 cls("") 造了个空文本消息;repr 显示空字符串为 `''`。
**4.** `2 2`。地雷引爆:logs 是类属性,s1 和 s2 **共享同一个列表**,两次 log 都进了同一个 logs。正确设计:`self.logs = []` 放进 __init__。这是今天最重要的一道题,做错的同学重看课件排错手册错误 6。

### 编程题 1:Todo 类(旧业务练新语法)

把 Day 05 的字典版待办升级为 `Todo` 类:属性 task、priority(默认"中")、done(默认 False);方法 `finish()` 标记完成、`format()` 返回 `✓/□ [优先级] 内容`、`to_dict()` / 类方法 `from_dict(data)`;构造时校验:task 非空(raise ValueError)、priority 必须是 高/中/低。附 assert 测试。

**参考答案(homework/todo_class.py):**

```python
# =============================================
# Day 08 作业 · 编程题 1:Todo 类
# 考点:构造即校验、默认参数、to_dict/from_dict 海关对
# =============================================


class Todo:
    """一条待办事项。"""

    VALID_PRIORITIES = ("高", "中", "低")           # 常量集合用元组

    def __init__(self, task: str, priority: str = "中", done: bool = False):
        if not task.strip():                        # 校验 1:内容非空
            raise ValueError("待办内容不能为空")
        if priority not in self.VALID_PRIORITIES:   # 校验 2:优先级合法
            raise ValueError(f"优先级必须是 {self.VALID_PRIORITIES} 之一")
        self.task = task.strip()                    # 进门先清洗:类里同样适用
        self.priority = priority
        self.done = done

    def finish(self) -> None:
        """标记完成。"""
        self.done = True

    def format(self) -> str:
        """展示行。"""
        mark = "✓" if self.done else "□"
        return f"{mark} [{self.priority}] {self.task}"

    def to_dict(self) -> dict:
        """出境海关:对象 → 字典(准备存 JSON)。"""
        return {"task": self.task, "priority": self.priority, "done": self.done}

    @classmethod
    def from_dict(cls, data: dict) -> "Todo":
        """入境海关:字典 → 对象(JSON 加载回来)。get 给默认值:容忍旧数据缺字段。"""
        return cls(data["task"], data.get("priority", "中"), data.get("done", False))


# ---- assert 测试 ----
t = Todo("写作业", "高")
assert t.format() == "□ [高] 写作业"
t.finish()
assert t.done and t.format().startswith("✓")
assert Todo.from_dict(t.to_dict()).task == "写作业"      # 海关往返无损

try:
    Todo("   ")                                # 空内容应被拒绝
    assert False
except ValueError:
    pass
try:
    Todo("x", "紧急")                          # 非法优先级应被拒绝
    assert False
except ValueError:
    pass
print("✓ Todo 类全部测试通过")
```

配套编程题 1,写 `TodoList` 类:属性 todos(Todo 对象列表);方法 `add(task, priority)`(重复 task 返回 False)、`finish(index)`(用户编号,越界返回 False)、`pending()` 返回未完成 Todo 列表、`stats()` 返回统计字典、`save(filename)` / 类方法 `load(filename)`(用 Day 07 的 JSON 模板 + 海关对:保存时逐个 to_dict,加载时逐个 from_dict)。

**参考答案(homework/todo_list_class.py)**:见代码文件。核心片段——**对象列表与 JSON 的双向转换**:

```python
    def save(self, filename: str = "todos.json") -> None:
        """整个清单落盘:对象列表 → 字典列表 → JSON 文件。"""
        data = [t.to_dict() for t in self.todos]        # 逐个过海关
        with open(filename, "w", encoding="utf-8") as f:
            json.dump(data, f, ensure_ascii=False, indent=2)

    @classmethod
    def load(cls, filename: str = "todos.json") -> "TodoList":
        """从磁盘复活整个清单:JSON 文件 → 字典列表 → 对象列表。"""
        book = cls()
        try:
            with open(filename, "r", encoding="utf-8") as f:
                data = json.load(f)
        except FileNotFoundError:
            return book                                  # 没文件:返回空清单
        book.todos = [Todo.from_dict(d) for d in data]   # 逐个入境
        return book
```

### 编程题 4:ChatSession 加会话存档 ★★(直通 Day 14)

给课堂的 ChatSession 增加两个方法:`save(filename)` 把会话(含名字和全部消息)存为 JSON;类方法 `load(filename)` 从文件复活会话。JSON 结构自己设计(提示:`{"session_name": ..., "messages": [...]}`)。这就是 Day 14 需求"对话历史保存为 JSON"的完整预制件。

**参考答案(homework/session_persist.py 关键部分):**

```python
    def save(self, filename: str) -> None:
        """会话存档:嵌套结构——外层会话信息,内层消息列表。"""
        data = {
            "session_name": self.session_name,
            "messages": [m.to_dict() for m in self.messages],
        }
        with open(filename, "w", encoding="utf-8") as f:
            json.dump(data, f, ensure_ascii=False, indent=2)

    @classmethod
    def load(cls, filename: str) -> "ChatSession":
        """从存档复活会话。"""
        with open(filename, "r", encoding="utf-8") as f:
            data = json.load(f)
        session = cls(data.get("session_name", "已恢复会话"))
        session.messages = [ChatMessage.from_dict(d) for d in data.get("messages", [])]
        return session
```

## 第五部分:思考题(2 题)

**思考题 1:** 读程序题 4 的 `logs` 类属性地雷,和 Day 06 的"默认参数用可变对象"地雷,底层是同一个原因吗?用"创建时机 + 共享"两个词组织你的答案。

**参考答案要点:** 同根。两者都是"**可变对象只在定义时创建一次,之后被所有使用方共享**":默认参数的列表在 def 执行时创建一次,所有调用共享;类属性的列表在 class 定义时创建一次,所有实例共享。而预期行为都是"每次/每个一份新的"。解药也同构:把创建动作搬进"每次都会执行的地方"——函数体内(if x is None: x=[])、__init__ 内(self.logs = [])。认出"同一个坑的两副面孔",说明抽象能力在长进。

**思考题 2:** ChatSession.save 存的 JSON 里有 session_name 和 messages。如果 Day 14 之后想给会话加"创建时间"、"使用的模型名"两个字段,旧的存档文件(没有这两个字段)还能被新代码 load 吗?怎么设计才能"新代码兼容旧数据"?

**参考答案要点:** 直接 `data["created_at"]` 会 KeyError 崩掉——旧档案没这个键。兼容设计:load 时用 `data.get("created_at", 默认值)`(Day 05 的抉择心法:可选字段用 get);from_dict 同理。这个问题的正式名字叫**数据格式演化/向后兼容**,工程惯例还包括:JSON 里存一个 `"version": 1` 字段,load 时按版本分支处理;新增字段永远给默认值;绝不重命名或删除旧字段(只标废弃)。Day 24 数据库迁移、Day 52 数据集版本管理,都是这个问题的放大版。能答出"用 get 给默认值"即合格,想到 version 字段即优秀。
