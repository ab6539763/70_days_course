# Day 08 思考记录(参考范例)

## 思考题 1:类属性地雷与默认参数地雷同根吗?

同根。两者都是"**可变对象只在定义时创建一次,之后被所有使用方共享**":

| | 创建时机 | 共享者 |
|---|---|---|
| 默认参数 `def f(x=[])` | def 执行时一次 | 所有调用 |
| 类属性 `class C: logs=[]` | class 定义时一次 | 所有实例 |

而预期行为都是"每次/每个一份新的"。解药同构:**把创建动作搬进每次都会执行的地方**——函数体内(`if x is None: x = []`)、`__init__` 内(`self.logs = []`)。

## 思考题 2:旧存档如何兼容新字段?

问题:新代码 `data["created_at"]` 读旧档案会 KeyError。

兼容设计(向后兼容/数据格式演化):
1. load/from_dict 一律用 `data.get("新字段", 默认值)`——可选字段用 get(Day 05 心法);
2. JSON 里存 `"version": 1`,load 按版本分支处理;
3. 新增字段永远给默认值;绝不重命名或删除旧字段(只标废弃)。
