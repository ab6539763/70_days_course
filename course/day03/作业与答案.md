### 选择题答案与解析

**1. A。** elif 从上到下**命中即退出**:x>5 为 True,打印 A 后整个结构结束,x>8 看都不看。这也提醒:本例条件顺序设计不当(宽条件在前,窄条件永远轮不到),复习课件 1.3 节"从严到宽单调排列"。
**2. A。** 起点 2,步长 3,含头不含尾:2、5、8,下一个 11 超过终点 10,停。
**3. B。** 口诀:break"不玩了",continue"这把不算,再来"。break 只砸当前一层。
**4. C。** n 永远是 0,条件永远 True,且循环体没有更新 n——while 三要素缺了"更新"。A 进循环立刻 break;B 正常倒数到 0;D 正常跑完(pass 是"什么都不做"的占位语句,顺便认识一下)。
**5. B。** 交互程序"待命等指令"的标准骨架,Day 14 的 AI 助手主循环就是它。
**6. B。** 含头不含尾的第三次出现(切片、range)。
**7. B。** isdigit 只认"纯数字字符":小数点不是数字字符,所以 False。同理 `"-5".isdigit()` 也是 False。这正是它能拦住小数和负数的原因,也是它的局限(拦掉了合法小数),完美方案等 Day 10 try/except。
**8. C。** for-else 的语义是"找了一圈没找到时做点什么",天然适合搜索场景的兜底。
**9. C。** randint 是"含头又含尾"的少数派,和 range/切片不同,容易混,考过就记住了。
**10. B。** Ctrl + C 发送中断信号,程序员的急刹车。

### 读程序题答案与解析

**1.** `37`。1 到 10 求和是 55,continue 跳过了 3 的倍数(3、6、9,共 18),55 - 18 = 37。考点:continue 跳过的是"本轮剩余代码",即 total += i 没执行。

**2.** `olleh`。每轮把新字符拼在结果**前面**(ch + result 而不是 result + ch),自然实现反转。对比 Day 02 的 `s[::-1]` 一行流:同一个需求,循环解法和切片解法都要会——面试官常要求"不用切片实现反转",这就是答案。

**3.** `243`。n 依次变成 3、9、27、81、243;243 ≥ 100,循环条件不满足,退出后打印。注意:判断发生在**每轮开始前**,所以 n 可以在循环内超过 100(81×3=243),最后一轮跑完才检查。

**4.** `全部合格`。三个词长度分别为 3、5、6——等等,"prompt" 是 6 > 5!会打印 `prompt 太长` 并 break,else 不执行。**故意设的坑**:请数清楚 p-r-o-m-p-t 是 6 个字母。答案是 `prompt 太长`。做错的同学记住教训:读程序题要真的逐字执行,不能扫一眼凭感觉。

### 编程题 1:BMI 计算器 2.0(联动 Day 01 作业)

升级 Day 01 的 `bmi.py`:① 输入校验:体重和身高必须是正数,否则重新输入(提示:isdigit 不认小数点,本题可先接收字符串,用 `replace(".", "", 1).isdigit()` 判断"最多带一个小数点的数字",或直接约定用户输入合法、只校验正负——两种方案都接受);② 根据 BMI 输出分级:< 18.5 偏瘦 / 18.5-24 正常 / 24-28 偏胖 / ≥ 28 肥胖。

**参考答案(homework/bmi_v2.py):**

```python
# =============================================
# Day 03 作业 · 编程题 1:BMI 计算器 2.0
# 考点:校验循环 + elif 分级(条件从严到宽单调排列)
# =============================================

# ---- 校验循环 1:体重 ----
while True:
    w_text = input("体重(公斤):").strip()
    # replace(".", "", 1) 删掉第一个小数点后再 isdigit:
    # "70.5" → "705" → True;"7..5" → "7.5" → False;"-70" → False
    if w_text.replace(".", "", 1).isdigit() and float(w_text) > 0:
        weight = float(w_text)
        break
    print("请输入正数!")

while True:
    h_text = input("身高(米,如 1.75):").strip()
    if h_text.replace(".", "", 1).isdigit() and float(h_text) > 0:
        height = float(h_text)
        break
    print("请输入正数!")

bmi = weight / (height * height)

# 分级:条件从严到宽,命中即退出
if bmi >= 28:
    level = "肥胖"
elif bmi >= 24:
    level = "偏胖"
elif bmi >= 18.5:
    level = "正常"
else:
    level = "偏瘦"

print(f"BMI = {bmi:.1f},分级:{level}")
```

注意两段校验循环几乎一模一样——复制粘贴的痛苦是故意留给你的,Day 06 学函数后这题要求重构成一个 `read_positive_number()` 用两次。

### 编程题 2:密码强度检查器

编写 `password_checker.py`:输入密码,按以下规则评分并输出强度:长度 ≥ 8 得 1 分;同时含大写和小写字母得 1 分;含数字得 1 分;含特殊字符(`!@#$%^&*` 之一)得 1 分。0-1 分弱、2-3 分中、4 分强。
提示:遍历密码的每个字符,用 `"a" <= ch <= "z"`(或 `ch.islower()` / `ch.isupper()` / `ch.isdigit()`)配合标志变量。

**参考答案(homework/password_checker.py):**

```python
# =============================================
# Day 03 作业 · 编程题 2:密码强度检查器
# 考点:for 遍历字符串 + 标志变量 + 多条件评分
# 标志变量(flag):先假设 False,循环中发现证据就翻成 True——高频模式
# =============================================

password = input("请输入密码:").strip()

# 四个标志变量,初始全为"未发现"
has_lower = False
has_upper = False
has_digit = False
has_special = False

SPECIALS = "!@#$%^&*"          # 特殊字符表:常量

for ch in password:            # 逐字符检查,每个字符最多点亮一个标志
    if ch.islower():
        has_lower = True
    elif ch.isupper():
        has_upper = True
    elif ch.isdigit():
        has_digit = True
    elif ch in SPECIALS:
        has_special = True

# 计分:bool 可以直接当 0/1 加(True 就是 1),这是 Python 的方便特性
score = 0
if len(password) >= 8:
    score += 1
if has_lower and has_upper:
    score += 1
if has_digit:
    score += 1
if has_special:
    score += 1

if score >= 4:
    strength = "强"
elif score >= 2:
    strength = "中"
else:
    strength = "弱"

print(f"得分 {score}/4,强度:{strength}")
```

### 编程题 3:星号金字塔(嵌套循环空间感训练)

用**双层循环 + 单个字符打印**(禁用字符串乘法)打印 5 层居中金字塔:

```
    *
   ***
  *****
 *******
*********
```

提示:第 i 层(1 起)= `5 - i` 个空格 + `2*i - 1` 个星号。

**参考答案(homework/pyramid.py):**

```python
# =============================================
# Day 03 作业 · 编程题 3:星号金字塔
# 考点:嵌套循环、行内两段循环(先空格后星号)、end=""
# 规律:第 i 层 = (N - i) 个空格 + (2i - 1) 个星号
# =============================================

N = 5                                  # 层数做成常量,改 9 层只动这里

for i in range(1, N + 1):              # 外层:第 1 到第 N 层
    for _ in range(N - i):             # 内层 1:先打空格(_ 表示用不到循环变量)
        print(" ", end="")
    for _ in range(2 * i - 1):         # 内层 2:再打星号
        print("*", end="")
    print()                            # 本层结束,换行

# 偷懒对照版(课堂变式 2 的思路,验证结果用):
# for i in range(1, N + 1):
#     print(" " * (N - i) + "*" * (2 * i - 1))
```

### 编程题 4:批量邮箱体检 ★(明天列表课的入场券)

Day 02 作业写过单个邮箱的解析。现在给一批邮箱(先照抄这个列表):

```python
emails = ["zhang@deepseek.com", "invalid-email", "li.si@qwen.ai", "@nouser.com", "wang@deepseek.com"]
```

用 for 遍历,对每个邮箱检查:含且只含一个 @(`count("@") == 1`)、@ 不在开头(`not startswith`)。输出每个邮箱的体检结果,最后统计合格数与合格率。

**参考答案(homework/email_batch.py):**

```python
# =============================================
# Day 03 作业 · 编程题 4:批量邮箱体检
# 考点:for 遍历列表 + 多条件校验 + 计数器 + 合格率计算
# 伏笔:对"一批数据"逐条校验再统计,是 Day 52 微调数据清洗的骨架
# =============================================

emails = ["zhang@deepseek.com", "invalid-email", "li.si@qwen.ai", "@nouser.com", "wang@deepseek.com"]

valid_count = 0                        # 合格计数器

for email in emails:
    # 两条校验规则,用 and 合并成一个判断
    is_valid = email.count("@") == 1 and not email.startswith("@")

    if is_valid:
        print(f"[合格] {email}")
        valid_count += 1
    else:
        print(f"[不合格] {email}")

total = len(emails)                    # len 对列表同样适用:元素个数
print("-" * 30)
print(f"合格 {valid_count}/{total},合格率 {valid_count / total:.0%}")
```

输出:合格 3/5,合格率 60%。做完这题你已经在"用列表"了——明天正式学它的增删改查,你会知道怎么把不合格的邮箱**挑出来单独装进另一个列表**(这个动作叫过滤,列表推导式一行搞定)。
