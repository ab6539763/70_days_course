**7. B。** f=format(时间→字符串);p=parse(字符串→时间)。方向靠这两个字母区分。

**9. C。** find 返回 -1、get 返回 None、search 返回 None——三兄弟同一个防御姿势:用前先判。
**10. B。** JSON 六种类型没有集合。落盘前 `sorted(集合)` 转列表。

### 编程题 1:会话存档管理器 ★(Day 14 /save /load 的后勤系统)

写三个函数并测试:
`save_session_auto(session_data: dict) -> str`:把会话字典存为 `sessions/session_20260716_1430.json`(sessions 目录自动创建,文件名带时间戳),返回文件路径;
`list_sessions() -> list`:列出 sessions 下所有存档(按文件名排序);
`load_latest() -> dict | None`:加载最新的一个存档(提示:时间戳文件名排序后取最后一个),没有存档返回 None。

**参考答案(homework/session_archive.py):**

```python
# =============================================
# Day 11 作业 · 编程题 1:会话存档管理器
# 考点:pathlib 建目录/glob、时间戳文件名、json 文件读写
# Day 14 的 /save 与"恢复上次会话"功能的后勤系统
# =============================================
import json
from datetime import datetime
from pathlib import Path

SESSIONS_DIR = Path("sessions")


def save_session_auto(session_data: dict) -> str:
    """存档会话:自动建目录 + 时间戳命名,返回文件路径。"""
    SESSIONS_DIR.mkdir(exist_ok=True)                 # 目录不存在就建,存在不报错
    name = f"session_{datetime.now().strftime('%Y%m%d_%H%M%S')}.json"
    path = SESSIONS_DIR / name
    with open(path, "w", encoding="utf-8") as f:
        json.dump(session_data, f, ensure_ascii=False, indent=2)
    return str(path)


def list_sessions() -> list:
    """列出所有存档路径,按文件名排序(时间戳命名 → 字典序即时间序!)。"""
    if not SESSIONS_DIR.exists():
        return []
    return sorted(SESSIONS_DIR.glob("session_*.json"))


def load_latest() -> dict | None:
    """加载最新存档;没有则 None。"""
    sessions = list_sessions()
    if not sessions:
        return None
    with open(sessions[-1], "r", encoding="utf-8") as f:    # 排序后最后一个=最新
        return json.load(f)


if __name__ == "__main__":
    import time
    p1 = save_session_auto({"name": "会话1", "messages": []})
    time.sleep(1.1)                    # 保证时间戳不同(秒级精度)
    p2 = save_session_auto({"name": "会话2", "messages": []})

    assert len(list_sessions()) >= 2
    latest = load_latest()
    assert latest["name"] == "会话2"   # 最新的是后存的
    print(f"✓ 存档管理器测试通过,最新存档:{latest['name']}")
```

亮点讲解:**时间戳命名的隐藏红利**——`%Y%m%d_%H%M%S` 格式保证"字典序 = 时间序",sorted 之后天然按时间排列,不需要读文件内容比时间。命名即索引,工程小巧思。

### 编程题 2:日志分析器(正则实战)

内置一段模拟服务日志(照抄),统计:①各级别(INFO/WARN/ERROR)条数;②所有 ERROR 行的时间和内容;③出现过的所有 IP 地址(去重排序)。

```python
LOG = """2026-07-16 10:01:22 INFO 用户登录成功 ip=192.168.1.5
2026-07-16 10:03:45 WARN 响应超时 ip=10.0.0.12 耗时=3.2s
2026-07-16 10:05:01 ERROR 数据库连接失败 ip=192.168.1.5
2026-07-16 10:06:33 INFO 用户查询订单 ip=172.16.0.3
2026-07-16 10:08:19 ERROR API限流 ip=10.0.0.12"""
```

**参考答案(homework/log_analyzer.py):**

```python
# =============================================
# Day 11 作业 · 编程题 2:日志分析器
# 考点:逐行处理、正则提取(分组)、计数器、集合去重
# =============================================
import re

LOG = """2026-07-16 10:01:22 INFO 用户登录成功 ip=192.168.1.5
2026-07-16 10:03:45 WARN 响应超时 ip=10.0.0.12 耗时=3.2s
2026-07-16 10:05:01 ERROR 数据库连接失败 ip=192.168.1.5
2026-07-16 10:06:33 INFO 用户查询订单 ip=172.16.0.3
2026-07-16 10:08:19 ERROR API限流 ip=10.0.0.12"""

# ① 级别计数:字典计数器
level_counter: dict = {}
# ② ERROR 详情收集
errors: list = []
# ③ IP 收集:集合去重
ips: set = set()

# 每行的通用模式:日期 时间 级别 消息
# 分组:(时间部分)(级别)(其余消息)——模式旁写人话是纪律
LINE_PATTERN = r"^(\d{4}-\d{2}-\d{2} \d{2}:\d{2}:\d{2}) (\w+) (.+)$"
IP_PATTERN = r"ip=(\d+\.\d+\.\d+\.\d+)"          # \. 转义:匹配字面的点

for line in LOG.split("\n"):
    m = re.match(LINE_PATTERN, line.strip())
    if not m:                                     # 匹配不上的行:跳过(容错)
        continue
    timestamp, level, message = m.group(1), m.group(2), m.group(3)

    level_counter[level] = level_counter.get(level, 0) + 1

    if level == "ERROR":
        errors.append(f"{timestamp}{message}")

    ip_match = re.search(IP_PATTERN, message)
    if ip_match:                                  # search 可能 None:先判再用
        ips.add(ip_match.group(1))

print("级别统计:", level_counter)
print("ERROR 详情:")
for e in errors:
    print(f"  {e}")
print("出现过的 IP:", sorted(ips))

assert level_counter == {"INFO": 2, "WARN": 1, "ERROR": 2}
assert len(ips) == 3
print("✓ 日志分析器测试通过")
```

### 编程题 4:chatlib 会话自动存档 ★★(汇入主线)

给 week2_project 的 ChatSession 增加方法 `autosave(dirname="sessions")`:按"会话名_时间戳.json"存档(复用编程题 1 的思路);同时给 ChatSession 增加**带时间戳的消息**——ChatMessage 增加可选属性 timestamp(默认 `datetime.now()` 的 ISO 字符串),to_dict/from_dict 同步升级(注意 Day 08 思考题 2 的向后兼容:旧存档没有 timestamp 字段也要能 load!)。

**参考答案(homework/chatlib_autosave.py 关键改动):**

```python
class ChatMessage:
    def __init__(self, role: str, content: str, timestamp: str = None):
        ...原有校验...
        # 默认参数地雷规避:不能写 timestamp=datetime.now().isoformat()!
        # (默认值在定义时求值一次,所有消息会共享同一个时间——Day 06 地雷的时间版)
        self.timestamp = timestamp or datetime.now().isoformat(timespec="seconds")

    def to_dict(self) -> dict:
        return {"role": self.role, "content": self.content, "timestamp": self.timestamp}

    @classmethod
    def from_dict(cls, data: dict) -> "ChatMessage":
        # get 默认 None → __init__ 里现生成:旧存档(无 timestamp)兼容!
        return cls(data["role"], data["content"], data.get("timestamp"))
```

**这题的暗桩**:默认参数如果写成 `timestamp: str = datetime.now().isoformat()`,就踩了 Day 06 的地雷(定义时求值一次,所有消息同一时间)。参考答案用 `None + or 现生成` 绕开。做题时踩没踩到,是检验 Day 06 知识是否真正长在身上的试金石。

## 第五部分:思考题(2 题)

**思考题 1:** 今天的关键词统计用"子串匹配"(count),答疑承认了"非会员"会误伤"会员"。假设你现在就要减轻这个问题(不引入分词库),能想到哪些土办法?各有什么代价?

**参考答案要点:** 土办法:①**前后字符检查**——匹配到"会员"后看前一个字是不是"非"(排除法,只能挡已知的误伤词,挡不住"高级会员制度"这类歧义);②**关键词加长**——统计"会员卡""会员价"等更具体的词(精确了但召回下降,漏掉单说"会员"的);③**正则边界**——中文没有 \b 词边界可用,收效有限。每个土办法都是"精确率与召回率的交换"——这对术语 Day 34 的 RAG 评估会正式定义,今天先体感:**抓得准和抓得全是一对天生的冤家**。根治靠分词(jieba)或更高级的语义匹配(Day 20 的 Embedding!)——"语义检索为什么胜过关键词检索",今天你已经摸到了答案的门把手。

**思考题 2:** 编程题 1 的"时间戳文件名 → 字典序即时间序"有一个隐藏前提。如果文件名格式改成 `session_2026-7-5.json`(月份日期不补零),排序还对吗?这说明设计"可排序的字符串"要注意什么?

**参考答案要点:** 会错:字典序比较逐字符进行,"2026-10-1" < "2026-7-5"(因为字符 '1' < '7')——10 月排到了 7 月前面。补零(07、05)让所有部分**定长**,字典序才与数值序一致。通用原则:**要按字符串排序的编号/日期,必须定长补零**(%m %d 天然补零,这就是标准格式代码的深意;同理订单号 0001-9999 而不是 1-9999)。这个坑在文件名、版本号(v9 > v10 的字典序陷阱)、Excel 排序里反复咬人,今天一次性免疫。
