### 选择题答案与解析

**1. B。** PATH 是操作系统的"程序通讯录",不勾选它,终端输入 `python` 时系统找不到解释器,报 `'python' 不是内部或外部命令`。补救:重新运行安装包 → Modify → 勾选 `Add Python to environment variables`,然后**重开终端**。

**2. C。** A 以数字开头非法;B 中划线 `-` 会被当作减号,非法;D `class` 是 Python 关键字,不能作变量名;C 符合"字母数字下划线、不以数字开头"的规则,且是标准的蛇形命名。

**3. C。** 被引号包住的一切都是字符串。`"3.14"` 是 4 个字符组成的文本,不是数字。想让它变成数字要 `float("3.14")`。

**4. B。** `input()` 的设计就是"把用户敲的那行字原样返回",不管用户输入 `28` 还是 `abc`,拿到的都是字符串。这是今天最重要的坑,请再默念一遍:input 返回值永远是 str。

**5. D。** `int()` 只接受"长得像整数"的字符串。`"28.5"` 带小数点,直接转会抛 `ValueError: invalid literal for int() with base 10: '28.5'`。正确做法是两步走:`int(float("28.5"))` → 28。

**6. A。** B 缺少 `f` 前缀,`{pi:.2f}` 会被原样输出;C 缺少大括号;D 缺少小数点,`:2f` 不是合法的两位小数格式(正确是 `:.2f`)。

**7. B。** `sep` 参数定义多个值之间的分隔符,默认是空格,这里改成了竖线。

**8. B。** `U+FF08` 是中文全角左括号的 Unicode 编号。中英文标点混用是零基础第一周的头号报错,检查输入法状态即可避免。

**9. C。** 完整流程:`git add`(放上打包台/暂存区)→ `git commit`(盖章记入本地账本)→ `git push`(推到云端 GitHub)。`git status` 只是查看状态,不产生任何改动。

**10. D。** 应用层岗位数量最多、门槛适中、最贴近业务,是零基础转行的最优入口。课程同时会在 Day 51-55 带你摸到模型层的边(微调),作为面试亮点。

**1. 写出下面程序的输出:**

```python

```

**2. 写出下面程序的输出:**

```python

```

**3. 下面程序会在第几行报错?报什么错?**

```python
age = input("年龄:")        # 用户输入了 30
next_age = age + 1
print(next_age)
```

**4. 写出下面程序的输出:**

```python
price = 9999.5
print(f"总价:{price:,.2f} 元")
print(f"折后:{price * 0.8:,.2f} 元")
```

### 读程序题答案与解析

**1.**
```
35
8
```
第一行是字符串拼接(`"3" + "5"` → `"35"`);第二行先转成整数再做算术加法。同一个 `+` 号,操作数类型不同,行为完全不同——这叫"运算符重载",明天(Day 02)运算符一节会系统讲。

**2.**
```
deepseek!deepseek!deepseek!
```
f-string 先把 `{name}` 填进去得到 `"deepseek!"`,字符串乘整数 = 重复拼接 3 次。

**3.** 第 2 行报错,`TypeError: can only concatenate str (not "int") to str`。因为 `input` 返回的是字符串 `"30"`,字符串不能与整数 `1` 相加。修复:`next_age = int(age) + 1`。

**4.**
```
总价:9,999.50 元
折后:7,999.60 元
```
`,` 是千分位分隔符,`.2f` 保留两位小数(不足补零,所以 9999.5 显示为 9,999.50)。第二行验证了 `{}` 里可以直接写表达式 `price * 0.8`。

### 编程题 1:BMI 计算器

编写 `bmi.py`:询问用户体重(公斤)和身高(米),计算并输出 BMI 值(体重 ÷ 身高的平方),保留一位小数。输出格式:`你的 BMI 是:22.5`。
提示:平方可以写作 `height * height`;除法用 `/`。

**参考答案(homework/bmi.py):**

```python
# =============================================
# Day 01 作业 · 编程题 1:BMI 计算器
# 考点:input + float 转换、算术运算、f-string 格式控制
# =============================================

# 体重和身高都可能带小数,所以用 float() 而不是 int()
weight = float(input("请输入你的体重(公斤):"))
height = float(input("请输入你的身高(米,如 1.75):"))

# BMI 公式 = 体重(kg) / 身高(m) 的平方
bmi = weight / (height * height)

# :.1f 保留一位小数
print(f"你的 BMI 是:{bmi:.1f}")
```

运行示例:输入 70 和 1.75,输出 `你的 BMI 是:22.9`。
常见错误:身高用了 `int()` → 输入 1.75 直接 ValueError;忘了给 `height * height` 加括号 → 由于除法乘法同级从左到右算,`weight / height * height` 等于 weight,结果错误但不报错——**不报错的逻辑错误比报错更危险**,明天讲运算优先级时会展开。

### 编程题 2:API 成本估算器 ★

大模型 API 按 token 计费。假设 DeepSeek 的价格是:输入 1 元/百万 token,输出 4 元/百万 token(课堂虚拟价,以官网为准)。编写 `cost.py`:询问用户"每天调用次数"、"平均每次输入 token 数"、"平均每次输出 token 数",计算并输出**每天**和**每月(按 30 天)**的成本,保留 4 位小数。

**参考答案(homework/cost.py):**

```python
# =============================================
# Day 01 作业 · 编程题 2:API 成本估算器
# 考点:多变量运算、常量提取、f-string
# 伏笔:Day 15 会用 tiktoken 真实计算 token 数,今天先建立成本意识
# =============================================

# ---- 常量区:价格写成常量,涨价时只改这里 ----
PRICE_INPUT_PER_M = 1.0     # 输入价:1 元 / 百万 token
PRICE_OUTPUT_PER_M = 4.0    # 输出价:4 元 / 百万 token
DAYS_PER_MONTH = 30         # 每月按 30 天估算

# ---- 输入环节 ----
calls_per_day = int(input("每天调用次数:"))
tokens_in = int(input("平均每次输入 token 数:"))
tokens_out = int(input("平均每次输出 token 数:"))

# ---- 处理环节 ----
# 每天总 token = 每次 token × 每天次数;除以 1_000_000 换算成"百万"单位
# (数字里的下划线是 Python 的千分位写法,纯粹为了人类可读,1_000_000 == 1000000)
daily_cost_in = calls_per_day * tokens_in / 1_000_000 * PRICE_INPUT_PER_M
daily_cost_out = calls_per_day * tokens_out / 1_000_000 * PRICE_OUTPUT_PER_M
daily_cost = daily_cost_in + daily_cost_out
monthly_cost = daily_cost * DAYS_PER_MONTH

# ---- 输出环节 ----
print(f"每天成本:{daily_cost:.4f} 元(输入 {daily_cost_in:.4f} + 输出 {daily_cost_out:.4f})")
print(f"每月成本(30 天):{monthly_cost:.4f} 元")
```

运行示例:输入 1000、500、300,输出:

```
每天成本:1.7000 元(输入 0.5000 + 输出 1.2000)
每月成本(30 天):51.0000 元
```

这道题的隐藏收获:你已经开始像大模型工程师一样思考成本了——输出 token 比输入贵 4 倍,所以 Day 16 学 `max_tokens` 参数限制输出长度,不只是技术问题,更是成本问题。
