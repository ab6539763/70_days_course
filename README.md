# 70 天大模型应用开发培训课程

本仓库包含完整的 **70 天零基础大模型应用开发培训课程** 课件，参考 SVM/K-Means/PCA 课件风格生成。

## 内容

- **70 天 Markdown 课件** — 纳米级粒度拆解，环环相扣
- **70 天配套代码** — 关键天提供完整可运行代码
- **70 天 PPT 课件** — 自动生成
- **PDF 导出脚本** — 支持 pandoc 批量导出

## 快速开始

```bash
cd course/scripts
./build_all.sh
```

课件从 [course/days/day01.md](course/days/day01.md) 开始阅读。

详见 [course/README.md](course/README.md)。
