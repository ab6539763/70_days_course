# 70_days_course

零基础大模型应用开发 70 天培训课程 — 完整课件仓库

## 快速开始

```bash
# 阅读课件（Markdown 格式，推荐）
cat courseware/phase1-python-basics/day01-开发环境与第一行代码.md

# 查看完整课表索引
cat courseware/README.md

# 导出 PDF（需 pandoc）
bash scripts/build_pdf.sh

# 导出 PPTX（需 python-pptx）
pip install python-pptx
python3 scripts/build_pptx.py
```
